# 🧹 MacTidy (En développement)

Projet d'apprentissage Java : création d'un utilitaire de nettoyage de disque local.

## 🏗️ État actuel du projet
Le moteur de base est fonctionnel. Il permet de :
- Parcourir un dossier cible prédéfini.
- Identifier et lister les fichiers selon des critères stricts (actuellement configurés sur : poids > 1 Mo ET inactivité > 30 jours).

## 🗺️ Prochaine étape
- Intégrer la classe `Scanner` pour rendre le programme interactif et permettre à l'utilisateur de définir ses propres critères directement dans la console.
